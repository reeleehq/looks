looks.params

looks.params¶

One parameter schema per effect: names, types, defaults and bounds, once.

An effect’s parameters used to live in three places that could drift: the compiler lambdas (a default read with params.get(name, DFLT)), the effect-level checks in looks.compile (ranges), and the research catalogue. Unknown keys were ignored, so colorbalance with shadow= (singular) compiled to an identity grade without a word.

EFFECT_PARAMS is the single declaration. It is read by check_params() (looks.compile calls it before an implementation is chosen, so every implementation of an effect accepts the same documents) and by with_defaults() (looks.compile fills defaults before a compiler or cost estimator runs, so the compilers read p["sigma"], never a second copy of the default). Keyed by EFFECT, never by implementation: two implementations of one effect must not disagree on what an omitted parameter means (rule 29b), and a check inside one compiler is a check the licence tier can switch off.

An effect with no entry here is unchecked: a caller’s own registered effects are theirs to validate. A parameter declared without a default stays absent when omitted, and the compiler decides (usually by refusing).

The checks refuse what ffmpeg would silently change or what is not a number: True and "0.5" are not floats, inf and nan are not finite, 7.9 is not a whole number (it would be emitted as 7).

Examples

>>> check_params("grain", {"strength": 7})
>>> check_params("grain", {"strenght": 7})
Traceback (most recent call last):
...
looks.params.ParamError: grain: unknown parameter 'strenght'; it takes ['seed', 'strength']
>>> with_defaults("grain", {"seed": 3})["strength"]
8

Module Attributes

NO_DEFAULT

A parameter with no default is left absent when omitted.

DFLT_VIGNETTE_ANGLE

Vignette half-angle, radians.

MAX_VIGNETTE_ANGLE

vignette clips its angle to [0, PI/2] instead of refusing, so a larger one would compile to a picture nobody asked for.

MAX_BLUR_SIGMA

gblur refuses a larger sigma ("Result too large"; 9.0 and 6.1).

DFLT_HALATION_TINT

film halation is the red layer scattering back off the base.

MAX_GRAIN_STRENGTH

noise's alls range is 0..100.

DFLT_GRAIN_SEED

Pinned rather than ffmpeg's own default, for portability across builds.

MAX_GRAIN_SEED

noise's all_seed tops out at INT_MAX; its -1 (a random seed) is below the range on purpose, since a seed is what makes grain reproducible.

DFLT_WEAVE_AMPLITUDE

Gate-weave wander, in pixels either side of centre.

DFLT_WEAVE_FREQUENCY

Horizontal and vertical wander, Hz.

DFLT_INTERP

lut3d's interpolation.

MAX_CUBE_SIZE

The largest .cube grid worth asking for (size**3 entries; ffmpeg's own limit is 256).

INTERP_MODES

lut3d's interp values.

MAX_POSTERIZE_LEVELS

One code value per level on an 8-bit channel; more levels than that is the identity, and an absurd count only makes a huge expression.

MAX_FLATTEN_SPATIAL

sigmaS 0..512, sigmaR 0..1, planes a 4-bit mask.

CURVES_CHANNELS

looks channel names to ffmpeg curves option names.

COLORBALANCE_ZONES

colorbalance tonal zones, keyed to the letter its options end in.

EFFECT_PARAMS

Effect -> its parameters.

PARAM_HINTS

A refused key that deserves more than "unknown parameter".

One named parameter: how to recognise a valid value, and what omitted means.

accepts is the strategy; the constructors below (real(), whole(), flag(), text(), vector(), curve(), anything()) cover every kind the registered effects need.

is_type()¶

Is the value of the right TYPE, bounds aside? A wrong type is reported as one, never as a bound it did not fail.

kind: str = 'any'¶

What sort of value this is, so a caller (or a test) can select parameters by it rather than by parsing expects.

looks.params.as_emitted(value)[source]¶

A number as the compilers write it into a filter string, read back.

A parameter check compares this, not the value asked for: six decimals are kept, so two curve x-points 1e-7 apart are written as one point, which curves refuses, and a vignette angle of 1e-9 is written 0.

>>> as_emitted(1e-9)
0.0
>>> as_emitted(0.1234567)
0.123457
Return type:

float

At least two (x, y) points in 0..1 with x strictly increasing.

Checked as emitted: x-points closer than the six decimals the compiler writes become one point, and curves refuses the curve. An empty value is accepted, because the compiler skips an empty channel too.
